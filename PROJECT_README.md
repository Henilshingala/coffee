# Koffee - Coffee Shop Website

## 📋 Project Overview
**Koffee** is a stylish **coffee shop website** showcasing a café's menu, atmosphere, and story. Perfect for coffee shops, cafés, or beverage businesses.

## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3
- **Type**: Static Website
- **Images**: PNG, JPG, WebP formats

## ✨ Pages

### 1. **Homepage** (index.html - 12.2KB)
- Welcome section
- Featured coffee
- Quick menu highlights
- Call-to-action

### 2. **Menu** (menu.html - 5.4KB)
- Coffee varieties
- Beverages
- Snacks and pastries
- Pricing

### 3. **About Us** (about-us.html - 3.1KB)
- Coffee shop story
- Values and mission
- Team introduction

### 4. **Contact** (contact.html - 4.2KB)
- Location and maps
- Contact form
- Phone and email
- Opening hours
